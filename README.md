تطبيق أندرويد متكامل ومخصص للمهندسين المدنيين والمشرفين الإنشائيين لحساب مواعيد كسر مكعبات الخرسانة (7 أيام، 28 يوم، 56 يوم)، وحساب الفروق بين التواريخ، بالإضافة إلى سجل محلي كامل لتتبع عينات الخرسانة بالمشاريع.

---

## 📸 المميزات الرئيسية (Features)

### 1. 🧪 حاسبة صب الخرسانة ومواعيد الكسر
* **حساب تلقائي دقيق:** حساب تواريخ الكسر المستقبلية لمكعبات الخرسانة فور تحديد تاريخ الصب.
* **فترات الاختبار القياسية والخاصة:**
  * **7 أيام:** اختبار المقاومة المبكرة (~65% - 70% من المقاومة).
  * **28 يوم:** اختبار المقاومة القياسية التصميمية (100%).
  * **56 يوم:** اختبار العناصر الخرسانية الضخمة والأسمنت بطيء الإمهاد (~110% - 115%).
  * **تاريخ مخصص:** إمكانية تحديد أي عدد أيام (مثل 3 أو 14 أو 90 يوماً).
* **عداد تنازلي وحالة الكسر:** توضيح الأيام المتبقية أو المنقضية لكل موعد كسر مع حالة ملونة واضحة.
* **حفظ بيانات الصبة:** تسجيل اسم المشروع، العنصر الإنشائي (سقف، أعمدة، قواعد)، رتبة الخرسانة (مثل C30/C35)، عدد المكعبات، وملاحظات الموقع.

### 2. 📅 حاسبة الفرق بين تاريخين
* حساب الفرق الزمني الدقيق بالـ **الأيام، الأسابيع، الشهور، والسنوات**.
* **أزرار إضافة سريعة (+7، +28، +56 يوماً)** لتسهيل الحسابات السريعة في الموقع.
* إمكانية اختيار التاريخ الجاري بضغطة زر واحدة.

### 3. 🗄️ سجل العينات المحفوظة (Room Database)
* قاعدة بيانات محلية آمنة لحفظ جميع العينات والمجموعات الخرسانية في الهاتف.
* **البحث السريع والتصفية:**
  * بحث باسم المشروع أو العنصر الإنشائي أو رتبة الخرسانة.
  * فلترة العينات (الكل / اختبارات قادمة / مكتملة الكسر).
* **مشاركة التقارير:** مشاركة نص منسق واحترافي لتقرير العينات الخرسانية عبر واتساب أو البريد الإلكتروني.
* **إدارة وتعديل السجل:** إمكانية حذف وتحديث العينات المحفوظة بمرونة.

### 4. 🎨 واجهة مستخدم Samsung One UI
* تصميم حديث وأنيق مستوحى من لغة تصميم **Samsung One UI**.
* دعم كامل للغة العربية واتجاه النص **من اليمين إلى اليسار (RTL)**.
* دعم الوضع النهاري والوضع الليلي (Light & Dark Theme).

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **اللغة:** Kotlin
* **واجهة المستخدم:** Jetpack Compose + Material Design 3 (One UI Theme)
* **البنية البرمجية:** MVVM (Model-View-ViewModel) + Clean Architecture
* **قاعدة البيانات المحلية:** Room Database + KSP
* **معالجة التزامن والأحداث:** Kotlin Coroutines & StateFlow
* **التاريخ والوقت:** Java Time API (`java.time.LocalDate`)

## 📥 كيفية التحميل والتثبيت (Installation)

### 1. التحميل المباشر بصيغة APK (Releases)
يمكنك تحميل ملف الـ APK وتثبيته مباشرة على هاتفك الذكي عبر اتباع الخطوات التالية:
1. اذهب إلى صفحة **[GitHub Releases](../../releases/latest)** الخاصة بالمستودع.
2. قم بتحميل ملف **`app-debug.apk`** أو **`concrete-calculator-v1.0-debug.apk`**.
3. افتح الملف على هاتفك واضغط على **تثبيت (Install)** (تأكد من السماح بتثبيت التطبيقات من مصادر خارجية إذا طُلب منك ذلك).

## ⚙️ بناء المشروع برمجياً (Building Source Code)

إذا كنت مطوراً وترغب في فتح وبناء المشروع على جهازك:

```bash
# 1. استنساخ المستودع
git clone https://github.com/YourUsername/YourRepo.git

# 2. الانتقال لفي المجلد
cd YourRepo

# 3. بناء ملف APK عبر Gradle
gradle assembleDebug
```

سيتم إنشاء ملف APK في المسار التالي:
`app/build/outputs/apk/debug/app-debug.apk`

## 🤖 البناء التلقائي عبر GitHub Actions (CI/CD)

يتضمن هذا المستودع ملف خطة عمل تلقائية (`.github/workflows/build-release.yml`) تقوم بـ:
1. بناء ملف الـ **APK** تلقائياً عند كل عملية `push` على الفرع الرئيسي `main`.
2. إنشاء **Release 1.0.0** مرفقاً به ملف الـ APK جاهزاً للتحميل بشكل آلي.
